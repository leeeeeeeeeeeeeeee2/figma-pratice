4. 주요 기능
기능 1: 신발 사이즈 기반 보드 길이 추천: 사용자가 신발 사이즈를 입력하면 발 크기에 맞는 보드 길이를 추천해, 스펙을 몰라도 자신에게 맞는 보드를 고를 수 있도록 함
기능 2: 컬러 조합 미리보기: 데크·휠·트럭 등 부품별 컬러를 직접 골라 조합하고, 완성된 보드 모습을 실시간으로 확인
기능 3: 모바일·데스크탑 반응형 레이아웃: 스마트폰에서도 컬러 선택과 사이즈 입력을 쉽게 조작할 수 있는 터치 친화적 UI
