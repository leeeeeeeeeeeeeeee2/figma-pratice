## 5. 트러블슈팅

### 이슈 1: [문제를 한 줄로]

- **문제**: 로컬 환경(Vite 개발 서버)에서는 정상 작동했으나, GitHub Pages에 배포한 직후 콘솔 에러와 함께 화면이 제대로 뜨지 않음
- **원인**: vite.config.js의 base 경로 설정이 기본값(/)으로 되어 있어, 깃허브 하위 경로(Repository 이름)를 찾아가지 못함
- **해결**: vite.config.js에 base: '/저장소이름/'을 명시하고 재배포하여 경로 문제 해결

## 6. AI 활용 방식

- **맡긴 일**:Figma에서 디자인한 시안을 바탕으로 React 기반의 모바일 반응형 UI 컴포넌트 및 인터랙션 구현
- **핵심 프롬프트**: "기존 수원시 도서관 앱에서는 도서 예약과 상호대차 신청 버튼이 숨겨져 있거나 비활성화되어 있어서 찾기가 너무 어려워. 사용자가 헤매지 않고 바로 신청할 수 있도록 도서 목록과 상세 화면에서 '도서 예약' 및 '상호대차 신청' 버튼을 눈에 띄게 활성화시켜서 배치해줘."

## 7. 회고# React + Vite

배운 점 : 기존 앱에서 불편했던 예약과 상호대차 기능을 사용자 입장에서 직접 개선해 보며, Figma 디자인부터 코드 구현, 배포까지 혼자 끝까지 완성해 내는 경험을 했다.
아쉬운 점 : 실제 도서관의 실시간 도서 데이터를 연결하지 못해 가상의 책 정보로만 화면을 구성한 점이 아쉽다.
